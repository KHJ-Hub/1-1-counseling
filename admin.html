교사용 학생 상담 관리

상담 예약과 학교 일정을 한 곳에서 관리합니다.

관리자 로그인

Apps Script에 설정된 관리자 비밀번호를 입력하세요.

관리자 대시보드

상담 예약 현황

비밀번호는 표시되지 않습니다. 상담 메모에는 민감정보를 입력하지 마세요.

상담 통계

필터 조건에 맞는 상담 현황을 집계합니다. 비밀번호와 상담 메모는 통계에 사용하거나 표시하지 않습니다.

학생별 상담 이력

학생 이름을 정확히 입력하면 같은 이름으로 등록된 상담을 조회합니다.

학교 일정 관리

개학식, 방학식, 시험, 체험학습, 재량휴업일 등 학생 달력에 표시할 학교 자체 일정을 등록합니다.

법정공휴일과 대체공휴일은 자동으로 달력에 표시됩니다. 이곳에는 학교 자체 일정만 등록해 주세요.
방학 일정은 날짜별 가능 시간이 열려 있을 때만 상담 신청이 가능합니다. 개교기념일·재량휴업일 등 상담이 어려운 일정은 상담 신청이 제한될 수 있습니다.

상담 불가일 관리

출장, 조퇴, 회의, 개인 일정 등 학생에게 자세히 공개하지 않고 상담만 막고 싶은 날짜를 등록합니다. 학생 화면에는 상세 사유 없이 상담 불가로 표시됩니다.

하루 전체 상담이 어려운 날에 사용합니다.
특정 차시만 막고 싶다면 “가능 시간” 탭에서 해당 차시를 비활성화합니다.

날짜별 상담 가능 시간

날짜별로 실제 상담 가능한 차시만 엽니다. 학기 중 평일은 기본 가능하며, 방학은 명시적으로 연 날짜만 가능합니다.

하루 전체가 불가능한 경우에는 “상담 불가일”을 사용할 수 있고, 특정 차시만 불가능한 경우에는 이 화면에서 해당 차시만 해제하세요.

가능 시간

기간 일괄 적용

기존 설정 보호를 위해 기본값은 건너뛰기입니다. 적용 전에 선택 내용을 다시 확인합니다.

적용 요일
가능 시간

상담 운영 상태

상담 신청을 전체적으로 열거나 닫고, 학생에게 보이는 안내문을 수정합니다.

기본 정보

학년도와 학급명, 화면 제목을 관리합니다. 보통 새 학년도 시작 전에만 수정합니다.

운영 기간

등록된 기간에 따라 현재 운영모드가 자동으로 판단됩니다.

현재 운영모드는 등록된 운영 기간과 오늘 날짜를 기준으로 자동 판단됩니다. 상담 운영 상태는 전체 신청을 열고 닫는 스위치이며, 학기 중/방학 모드는 수동으로 매번 바꾸지 않아도 됩니다. 방학이 끝나면 별도 조작 없이 학기 중 모드로 돌아갑니다.

기간 목록

차시 시간표

상담 가능한 차시의 실제 시작·종료 시간을 관리합니다. 시간표가 바뀔 때만 수정합니다.

관리자 저장값이 기존 Script Properties보다 우선합니다.

새 학년도 준비

새 학년으로 넘어가기 전에 기존 데이터를 백업하고 기본 정보를 변경합니다.

새 학년도 시작 전, 현재 데이터를 백업한 뒤 학년도·학급명과 상담 가능 시간을 새 학년도에 맞게 조정하세요.

  • 기존 예약과 상담 이력은 삭제하지 않고 보관하는 것을 권장합니다.
  • 백업 버튼은 원본 데이터를 삭제하지 않고 복사본만 만듭니다.
  • 상담 가능 시간 초기화가 필요하면 백업 후 필요한 항목만 직접 정리하세요.
  • 이 화면에서는 위험한 일괄 삭제 기능을 제공하지 않습니다.
