교사용 상담 관리

상담 예약과 학사일정을 한 곳에서 관리합니다.

관리자 로그인

Apps Script에 설정된 관리자 비밀번호를 입력하세요.

관리자 대시보드

상담 예약 현황

비밀번호는 표시되지 않습니다. 상담 메모에는 민감정보를 입력하지 마세요.

상담 통계

필터 조건에 맞는 상담 현황을 집계합니다. 비밀번호와 상담 메모는 통계에 사용하거나 표시하지 않습니다.

학생별 상담 이력

학생 이름을 정확히 입력하면 같은 이름으로 등록된 상담을 조회합니다.

학사일정 관리

등록된 기간은 기존 동작대로 상담 불가 기간에도 포함됩니다.

상담 불가 기간 관리

일정명은 시트에 “상담불가”로 저장됩니다.

날짜별 상담 가능 시간

별도 설정이 없는 날짜는 세 시간 모두 예약 가능합니다.

가능 시간

알림 및 연동 설정 안내

실제 URL·Calendar ID·비밀값은 화면과 API 응답에 표시하지 않습니다.

관리자 비밀번호 변경

변경 후 모든 관리자 세션이 만료되어 다시 로그인해야 합니다.
