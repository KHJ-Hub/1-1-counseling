# 1학년 1반 상담 예약

Google Apps Script와 Google Sheets를 사용하는 상담 예약 사이트입니다. 학생은 달력에서 상담을 예약하거나 본인 예약을 취소할 수 있고, 교사는 별도 관리자 화면에서 예약·상담 기록·학사일정·상담 가능 시간을 관리할 수 있습니다.

## 파일 구조

- `index.html`, `styles.css`, `script.js`: 학생용 상담 예약 화면
- `admin.html`, `admin.css`, `admin.js`: 교사용 관리자 화면
- `apps-script/Code.gs`: Google Sheets 조회·변경 및 관리자 인증 서버
- `AGENTS.md`: 프로젝트 수정 규칙

학생 화면과 관리자 화면은 같은 Google Apps Script 웹 앱 URL을 사용합니다. 기존 URL, 학생용 `save`·`delete` 요청 필드와 기존 성공 응답은 변경하지 않습니다.

## Google Sheets 설정

시트 이름과 기존 열의 위치를 변경하지 마세요.

### 상담신청현황

| 열 | 헤더 | 설명 |
|---|---|---|
| A | 날짜 | 기존 예약 날짜 |
| B | 시간 | 기존 상담 시간 |
| C | 이름 | 기존 학생 이름 |
| D | 비밀번호 | 기존 학생 예약 비밀번호 |
| E | 상담완료 | 관리자 화면에서 저장하는 `TRUE/FALSE` 값 |
| F | 상담메모 | 관리자용 일반 텍스트 메모 |

E1에 `상담완료`, F1에 `상담메모`를 추가합니다. 기존 A~D 열은 이동하거나 변경하지 않습니다. 학생 비밀번호는 기존 호환성을 위해 D열에 저장되지만 공개 조회와 관리자 응답에는 포함되지 않습니다.

상담 메모에는 건강정보, 연락처 등 민감정보를 입력하지 마세요.

### 학사일정

기존 구조를 그대로 사용합니다.

| 열 | 헤더 | 설명 |
|---|---|---|
| A | 시작일 | 일정 시작일 |
| B | 종료일 | 일정 종료일 |
| C | 일정명 | 학사일정 이름 또는 `상담불가` |

모든 학사일정 기간은 기존 동작대로 학생 상담 불가 기간에도 포함됩니다. C열이 비어 있거나 `상담불가`인 행은 관리자 화면의 상담 불가 목록에 표시됩니다.

### 상담가능시간

`상담가능시간`이라는 새 시트를 만들고 다음 헤더를 1행에 입력합니다.

| 열 | 헤더 | 값 |
|---|---|---|
| A | 날짜 | 날짜 |
| B | 야자 1차시 | `TRUE` 또는 `FALSE` |
| C | 야자 2차시 | `TRUE` 또는 `FALSE` |
| D | 야자 3차시 | `TRUE` 또는 `FALSE` |

날짜별로 한 행만 사용합니다. 별도 행이 없는 날짜는 세 시간 모두 가능한 것으로 처리됩니다. 해당 시트가 아직 없어도 학생 화면은 기존 기본값으로 동작하지만, 관리자 화면의 가능 시간 관리는 사용할 수 없습니다.

## 관리자 비밀번호 설정

관리자 비밀번호 원문을 HTML, JavaScript, `Code.gs` 또는 Git 저장소에 기록하지 마세요.

1. Apps Script 편집기에서 프로젝트 설정을 엽니다.
2. Script Properties에 `ADMIN_PASSWORD_SETUP`을 추가하고 초기 관리자 비밀번호를 임시로 입력합니다.
3. Apps Script 편집기에서 `initializeAdminPassword()`를 한 번 직접 실행하고 권한을 승인합니다.
4. `ADMIN_PASSWORD_HASH`, `ADMIN_PASSWORD_SALT`, `ADMIN_AUTH_VERSION`이 생성되었는지 확인합니다.
5. 원문을 담은 `ADMIN_PASSWORD_SETUP`이 자동 삭제되었는지 확인합니다.

로그인 성공 시 30분짜리 임시 세션이 발급됩니다. 모든 관리자 요청은 서버에서 세션을 다시 검사합니다. 관리자 화면에서 비밀번호를 변경하면 기존 세션은 모두 무효화됩니다.

## Discord Webhook 설정

Discord Webhook URL은 코드나 Git 저장소에 기록하지 않고 Apps Script의 Script Properties에만 저장합니다.

1. Apps Script 편집기에서 **프로젝트 설정 → 스크립트 속성**을 엽니다.
2. `DISCORD_WEBHOOK_URL`에 Discord에서 발급한 Webhook URL을 입력합니다.
3. `testDiscordNotification()`을 편집기에서 한 번 실행하고 Discord 테스트 메시지를 확인합니다.

예약 성공 알림에는 학생 이름, 상담 날짜, 상담 시간, 관리자 페이지 링크만 포함됩니다. 취소 성공 알림에는 학생 이름, 상담 날짜, 상담 시간만 포함됩니다. 학생 비밀번호와 상담 메모는 전송하지 않습니다. 알림 전송에 실패해도 예약·취소 결과에는 영향을 주지 않으며 실패 사실만 Apps Script 실행 로그에 남습니다.

## 관리자 화면 사용법

`admin.html`에서 다음 기능을 사용할 수 있습니다.

- 전체 예약 조회와 이름·날짜·시간 필터
- 관리자 권한 예약 삭제
- 상담 완료 여부와 상담 메모 저장·수정
- 정확한 학생 이름으로 상담 이력 조회
- 학사일정 추가·수정·삭제
- 상담 불가 기간 추가·수정·삭제
- 날짜별 야자 1·2·3차시 가능 여부 설정
- 관리자 비밀번호 변경

관리자 응답에는 `상담신청현황` D열의 학생 비밀번호가 포함되지 않습니다.

## Apps Script 반영 및 재배포

1. 현재 Google Sheets와 Apps Script 코드를 백업합니다.
2. `상담신청현황` E1/F1 헤더를 추가합니다.
3. 위 구조대로 `상담가능시간` 시트를 생성합니다.
4. 저장소의 `apps-script/Code.gs` 전체를 연결된 Apps Script 프로젝트에 반영합니다.
5. 관리자 비밀번호와 Discord Webhook의 Script Properties 설정을 완료합니다.
6. Apps Script에서 **배포 → 배포 관리**를 엽니다.
7. 기존 웹 앱 배포를 편집하고 새 버전으로 업데이트합니다.
8. 실행 사용자와 접근 권한은 현재 운영 설정을 유지합니다.
9. 새 배포를 별도로 만들지 말고 기존 배포 ID를 업데이트하여 기존 웹 앱 URL을 유지합니다.
10. `testDiscordNotification()`과 학생 조회·신청·취소를 먼저 확인한 다음 관리자 기능을 확인합니다.

문제가 발생하면 배포 관리에서 이전 정상 버전으로 되돌립니다.

## 개인정보 및 보안 주의

- 기존 동작 호환을 위해 학생 이름은 학생 달력에 그대로 표시됩니다. 사이트 접근 범위를 필요한 사용자로 제한하세요.
- 학생 예약 비밀번호는 응답 데이터, 관리자 목록, 상담 이력에 포함되지 않습니다.
- 관리자 세션 성공 여부를 프런트엔드만으로 판단하지 않으며 모든 관리 action에서 서버 인증을 수행합니다.
- 상담 메모에는 민감정보를 입력하지 않습니다.
- 서버 내부 예외 상세는 사용자 화면에 표시하지 않습니다.

## 수동 테스트 체크리스트

### 학생 기능

- 달력에서 기존 예약과 모든 학사일정이 정상 표시되는지 확인
- 학사일정 기간에는 예약할 수 없는지 확인
- 설정이 없는 날짜에 세 시간이 모두 표시되는지 확인
- `상담가능시간`에서 `FALSE`인 시간은 선택할 수 없는지 확인
- 같은 날짜·시간에 두 요청이 들어오면 한 건만 저장되는지 확인
- 같은 학생의 주 1회 제한이 유지되는지 확인
- 숫자 4자리 비밀번호로 예약하고 같은 비밀번호로 취소할 수 있는지 확인
- 잘못된 비밀번호로는 취소할 수 없는지 확인
- 제출 중 버튼이 비활성화되는지 확인
- 네트워크 오류와 서버 오류 안내가 이해하기 쉽게 표시되는지 확인

### 관리자 기능

- 정상·오류 로그인과 30분 세션 만료 확인
- 인증 정보가 없거나 잘못된 모든 관리자 action이 거부되는지 확인
- 예약 검색·필터·삭제 후 시트와 학생 달력에 반영되는지 확인
- 상담 완료·메모가 E/F열에 저장되고 재조회되는지 확인
- 학생 이력에 비밀번호가 포함되지 않는지 확인
- 학사일정과 상담 불가 기간의 추가·수정·삭제 확인
- 날짜별 가능 시간의 추가·수정·삭제와 학생 화면 반영 확인
- 관리자 비밀번호 변경 후 기존 세션이 만료되는지 확인
- 예약 성공 직후 Discord에 이름·날짜·시간·관리자 링크만 전송되는지 확인
- 학생 취소 직후 Discord에 이름·날짜·시간만 전송되는지 확인
- Webhook URL을 잘못 설정해도 예약·취소가 정상 완료되는지 확인
- 모바일에서 목록, 입력 폼, 삭제 확인창이 잘리지 않는지 확인
- Tab 이동과 ESC 닫기가 정상 동작하는지 확인

## 로컬 확인

정적 파일 서버에서 프로젝트 루트를 실행합니다.

```sh
python -m http.server 4173
```

`http://127.0.0.1:4173/`과 `http://127.0.0.1:4173/admin.html`을 확인합니다. 실제 Google Sheets 변경 테스트는 수정된 Apps Script를 기존 웹 앱에 재배포한 뒤 수행해야 합니다.
